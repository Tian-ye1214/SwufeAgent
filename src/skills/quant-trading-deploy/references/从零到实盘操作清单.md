## 阶段1：准备工作（东方财富APP）

### 1.1 完成风险测评（5分钟）

这是必须步骤，不完成无法交易ETF。

```
打开东方财富APP → 我的 → 业务办理 → 风险测评
按实际情况答题（共20题左右）
```

完成后你会得到一个风险等级（如 C3 稳健型、C4 成长型等），**C3及以上**即可交易ETF。

### 1.2 确认ETF交易权限

```
东方财富APP → 交易 → 买入 → 输入 510300
```

如果提示「无权限」或「需签署协议」，按提示在线签署即可（通常是《ETF交易风险揭示书》，电子签名）。

### 1.3 入金确认

确保交易账户可用资金 ≥ 1000 元（1手510300约470元 + 缓冲）。

## 阶段2：安装东方财富量化终端（PC端）

### 2.1 下载终端

**下载地址**：https://emquant.18.cn

> 或搜索「东方财富量化终端」「东财掘金量化」「EMQuant」

选择 **Windows 版** 下载安装（目前仅支持 Windows）。

### 2.2 安装 Python 环境

终端内置 VS Code 编辑器，但需要你本机有 Python：

```
方式A（推荐）：下载 Anaconda → https://www.anaconda.com/download
方式B：下载 Python 3.9+ → https://www.python.org/downloads/
```

安装后验证：
```bash
python --version   # 应显示 Python 3.9.x 或更高
```

### 2.3 安装策略SDK

```
打开东方财富量化终端 → 左下角「量化」→ 等待自动安装
→ 左上角「SDK下载」→ 选择 Python → 安装
```

安装成功后，可以在 Python 中验证：
```python
from gm.api import *
print('SDK安装成功')
```

### 2.4 获取 Token ID

Token 是连接你账户和策略的关键凭证：

```
终端 → 右上角用户图标 → 用户管理 → 密钥管理
→ 复制 Token ID（一串类似 "2c4e3c59..." 的字符串）
```

> ⚠️ Token 绑定你的电脑和账户，不要泄露给他人。

- ✅ 信号判断准确（金叉买、死叉卖）

## 阶段4：切换实盘

### 4.1 确认能否开通实盘

```
终端 → 实盘交易 → 账户管理 → 添加实盘账户
```

如果提示「资金不足」或「不满足开通条件」，说明存在资金门槛。此时有两种选择：

| 情况 | 方案 |
|------|------|
| 成功连接实盘 | 直接进入 4.2 |
| 提示资金门槛（如需10万） | 切回仿真模式继续积累，或换券商（如国金证券10万门槛较低） |

### 4.2 实盘启动（小资金）

首次实盘建议：
```
1. 确认账户内有5000元可用资金
2. 先在终端设置风控参数：
   终端 → 实盘交易 → 风控设置 →
   - 单笔最大买入金额：5000
   - 持仓上限：5000
   - 日亏损上限：200（亏4%停）
3. 点击「运行」启动策略
```

### 4.3 日常监控

实盘运行后，每天检查一次：
- 终端「策略监控」页面看日志
- 东方财富APP 核对持仓和成交
- 特别关注：**有没有出现金叉/死叉时未成交的情况**

## 常见问题

### Q1: 策略跑了几天都没信号，正常吗？
**正常。** 双均线策略可能几周甚至几个月才出现一次交叉信号。没信号就空仓等，这是策略的一部分。

### Q2: 下单后没成交怎么办？
代码用的是限价单（Limit），如果价格波动快可能没成交。可以考虑改为市价单：把 `order_type=OrderType_Limit` 改成 `order_type=OrderType_Market`。

### Q3: 每天 14:50 执行，万一当天出现信号但第二天才买入怎么办？
因为用的是日线收盘价判断，14:50 离收盘只有10分钟，基本能拿到当天收盘价附近的价格。如果想更接近收盘价，可以改成 `14:55:00`。

### Q4: 能同时监控多个ETF吗？
可以。在代码中修改 `SYMBOL` 或扩展为列表，用 `subscribe` 订阅多个标的。但5k本金建议先专注一只。

### Q5: 真亏了怎么办？
双均线策略最大回撤在6%左右，5000元最多亏约300元。如果亏到这个幅度策略会自动止损吗？——当前版本没有止损，你可以提需求我帮你加上。
