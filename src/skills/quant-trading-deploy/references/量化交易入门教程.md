## 第一章：量化交易是什么？

### 1.1 一句话定义

**量化交易 = 用程序代替人做决策。**

传统交易员靠「看盘感觉 + 经验直觉」买卖股票；量化交易员把同样一套规则写成代码，让计算机自动执行。就像**自动驾驶**取代**手动驾驶**——规则一样，但执行者从人变成了机器。

### 1.2 打个比方：做饭 vs 用菜谱机器人

| | 传统交易 | 量化交易 |
|---|---|---|
| **好比** | 凭手感做饭 | 用智能料理机按菜谱做 |
| **决策依据** | 「感觉差不多了」「这票要涨」 | 「MA10 > MA30 就买入」 |
| **情绪影响** | 害怕、贪婪、犹豫 | 零情绪，严格执行 |
| **可重复性** | 今天赚了明天不一定 | 同样的条件 → 同样的操作 |
| **下班后** | 还得操心持仓 | 机器自动盯着 |

### 1.3 量化交易的四大优势

| 优势 | 解释 |
|------|------|
| 🧊 **克服人性弱点** | 该买就买、该卖就卖，不恐惧不贪婪 |
| ⏱️ **7×24 小时工作** | 机器不需要睡觉，实时监控市场 |
| 📊 **多市场并行** | 同时监控几百只股票，人做不到 |
| 🔬 **可验证** | 策略好不好？用历史数据回测一下就知道 |

### 1.4 量化交易的完整流程

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│  数据获取  │ → │  策略计算  │ → │  信号生成  │ → │  执行交易  │ → │  结果分析  │
│ (akshare) │   │ (MA计算)  │   │ (金叉/死叉)│   │ (模拟买入) │   │ (收益率等) │
└──────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘
      ↓               ↓               ↓               ↓               ↓
  下载价格        算均线          判断买卖         记录操作        算账、画图
```

**本教程带你走通上述全过程**，用真实的A股数据和代码。

## 第二章：核心概念字典

> 每个术语第一次出现时，我会用 **生活类比** 解释清楚。先混个眼熟，后面用到时会再展开。

### 2.1 因子（Factor）—— 🃏 选股打分卡

**因子**就是影响股票涨跌的某一类特征。好比你去**选餐厅**：

| 你选餐厅考虑的因素 | 量化选股对应的因子 |
|---|---|
| 评分高不高 | 动量因子（过去涨得好不好） |
| 价格便不便宜 | 估值因子（市盈率PE高低） |
| 排队久不久 | 换手率因子（交易活跃度） |

**关键理解**：因子就是**一张打分表上的一个评分项**。多个因子合起来 = 完整的评分系统。

**本教程只用了一个因子**：**移动平均线（MA）**——最简单、最经典的价格类因子。

### 2.2 交易策略（Strategy）—— 📖 交易规则书

**策略**是一套完整的规则手册，告诉计算机：**什么时候买、什么时候卖、买多少**。

类比：就像**烘焙食谱**——

```
食谱说：
  1. 烤箱预热到180度    → 策略说：数据准备好
  2. 面糊倒入模具        → 策略说：触发买入条件
  3. 烤30分钟取出        → 策略说：触发卖出条件
```

**一个完整的策略包含三个要素：**

```
┌─────────────────────────────────────────────────┐
│ ① 信号生成规则  → 什么时候该交易                    │
│ ② 仓位管理规则  → 每次买多少/卖多少                │
│ ③ 风险控制规则  → 亏多少就止损/止盈                │
└─────────────────────────────────────────────────┘
```

### 2.3 回测（Backtest）—— 📝 历史模拟考试

**回测**就是用**过去的历史数据**模拟运行你的策略，看看如果当时按这个策略操作，能赚多少钱。

**类比：高考模拟卷**

| 高考模拟 | 量化回测 |
|---------|---------|
| 做历年真题 | 用历史行情数据 |
| 检验复习水平 | 检验策略可靠性 |
| 模拟分数≠高考分数 | 回测收益≠未来收益 |
| 做错的题要及时纠正 | 策略亏损要分析原因 |

**回测的核心指标：**

| 指标 | 含义 | 生活类比 | 多少算好 |
|------|------|---------|---------|
| **累计收益率** | 最终赚/亏了多少 | 年终奖涨了多少 | 越高越好 |
| **年化收益率** | 折算成每年赚多少 | 年化利率 | >10% 不错，>20% 优秀 |
| **最大回撤** | 从最高点跌倒最低点 | 坐过山车的最大落差 | <20% 较好 |
| **夏普比率** | 每承担1分风险赚多少收益 | 性价比 | >1 不错，>2 优秀 |
| **交易次数** | 总共买卖了多少次 | 你打车的次数 | 太少说明策略不活跃 |

### 2.4 实盘（Live Trading）—— 🎯 真枪实弹上场

**实盘**就是用**真金白银**在实际市场中交易。跟回测完全不同。

| 回测 | 实盘 |
|------|------|
| 用过去的数据 | 面对未来的未知 |
| 不用担心成交不了 | 可能买不到/卖不掉 |
| 没有情绪影响 | 真亏钱会心慌 |
| 理论上完美执行 | 实际有延迟、有滑点 |

**标准进阶路径（永远不要跳步）：**

```
回测验证（历史数据）
   ↓
模拟盘（当前行情模拟）
   ↓
小资金实盘（先试水）
   ↓
正常实盘（稳定盈利后）
```

### 2.5 滑点（Slippage）—— 🏪 超市排队价格变了

**滑点**是你下单时和实际成交时之间的价格差异。

**生活类比**：

> 你去超市买苹果，收银台屏幕上显示 **5元/斤**。  
> 你排队结账，轮到你时发现价格变成了 **5.2元/斤**。  
> **这0.2元的差价就是「滑点」**。

在股市中：
- 你看到某股票**10.00元**，决定买入
- 等你的订单传到交易所，价格已经变成**10.05元**
- 或者你的订单量太大，直接把价格推到了**10.03元**

**在回测中处理滑点**：通常会在买卖价格上增加一个固定滑点率（如万分之五），让回测更接近实盘。

### 2.6 手续费（Commission）—— 💸 交易成本

**手续费**是每一次买卖必须支付给券商和交易所的费用。

**类比**：就像你用**支付宝/微信提现**要收手续费一样。

**A股交易的主要费用：**

| 费用项目 | 费率 | 说明 |
|---------|------|------|
| 佣金 | 万1~万3 | 给券商的，买卖都收 |
| 印花税 | 万分之5（卖出收） | 给国家的，只有卖出时收 |
| 过户费 | 万分之0.1 | 给登记结算公司，买卖都收 |

> 💡 **不要小看手续费！** 假设每次买卖成本0.05%，一年交易50次就是2.5%的纯成本——如果你的策略年化收益只有5%，手续费就吃掉了一半利润。

## 第三章：双均线策略详解

### 3.1 什么是移动平均线（Moving Average, MA）

**移动平均线**就是过去 N 天的**平均收盘价**连成的线。作用是**平滑价格波动**，帮助你看到趋势方向。

```
MA5  =  最近5天的收盘价之和 ÷ 5
MA10 =  最近10天的收盘价之和 ÷ 10
MA30 =  最近30天的收盘价之和 ÷ 30
```

**形象理解**：

```
价格波动像┌╱╲╱╲╱╲╱╲╱╲┐这样上蹿下跳
均线就像 ──────────── 一条平滑的曲线
```

- **短期均线（MA10）**：反应快，紧跟价格，像灵敏的🐕小狗
- **长期均线（MA30）**：反应慢，走势平滑，像稳重的🐢乌龟

### 3.2 金叉（Golden Cross）—— 🟢 买入信号

**金叉 = 短期均线上穿长期均线**，是**买入信号**。

```
价格
↑
│  短期MA──── 上穿 │
│  ╱               │
│ ╱  长期MA────    │
│╱                  │
│                   │
└──────────────────→ 时间
      ↑
    金叉发生处
```

**背后逻辑**：短期均价超过了长期均价 → 最近的价格在上涨 → 趋势由跌转涨 → **该买入了**

### 3.3 死叉（Death Cross）—— 🔴 卖出信号

**死叉 = 短期均线下穿长期均线**，是**卖出信号**。

```
价格
│
│   长期MA────      │
│  ╲  短期MA 下穿   │
│ ╲  ────           │
│╱                  │
│                   │
└──────────────────→ 时间
      ↑
    死叉发生处
```

**背后逻辑**：短期均价跌破长期均价 → 最近的价格在下跌 → 趋势由涨转跌 → **该卖出了**

### 3.4 完整图解：金叉→持仓→死叉→空仓

```
价格
↑
│   ╱╲              ╱╲
│  ╱  ╲            ╱  ╲      短期均线（MA10）───
│ ╱    ╲          ╱    ╲     ╱
│╱      ╲        ╱      ╲   ╱
│        ╲      ╱        ╲ ╱       长期均线（MA30）───
│         ╲    ╱          ╳
│          ╲  ╱          ╱ ╲
│           ╲╱          ╱   ╲
│            ╳         ╱     ╲
│           ╱ ╲       ╱       ╲
│          ╱   ╲     ╱         ╲
│         ╱     ╲   ╱           ╲
│        ╱       ╲╱             ╲
│       ╱         ↑               ↑
│      ╱       死叉卖出         死叉卖出
│     ╱
│    ↑
│  金叉买入
│
└────────────────────────────────────────→ 时间
     ↑持仓中↑        ↑空仓等待↑       ↑持仓中↑
```

### 3.5 本教程使用的参数

| 参数 | 值 | 说明 |
|------|-----|------|
| **短期均线（快线）** | MA10（10日均线） | ≈ 最近两周的交易趋势 |
| **长期均线（慢线）** | MA30（30日均线） | ≈ 最近一个半月的交易趋势 |
| **交易标的** | 510300（沪深300ETF） | 跟踪沪深300指数，买它≈买一篮子A股核心资产 |
| **时间范围** | 最近1年（约250个交易日） | 2025-05 ~ 2026-04 |
| **初始资金** | 100,000元 | 模拟本金 |
| **仓位管理** | **全仓进出** | 有信号就全部买入/卖出 |

### 3.6 完整的策略规则

```
┌─────────────────────────────────────────────────────────┐
│                   双均线策略规则书                         │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  买入条件：MA10 从下方上穿 MA30（形成金叉）               │
│    ├─ 前提：当前空仓                                     │
│    └─ 操作：用全部现金，以收盘价全仓买入                   │
│                                                         │
│  卖出条件：MA10 从上方下穿 MA30（形成死叉）               │
│    ├─ 前提：当前持有仓位                                 │
│    └─ 操作：卖出全部持仓，回到空仓状态                    │
│                                                         │
│  持仓期间：持有不动，不进行任何操作                       │
│  空仓期间：持有现金，不进行任何操作                       │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 4.3 关键代码段详解

#### 第一步：获取数据

```python
import akshare as ak
# 通过新浪接口获取ETF历史日K线
df = ak.fund_etf_hist_sina(symbol='sh510300')
df['date'] = pd.to_datetime(df['date'])
df.set_index('date', inplace=True)
# 筛选最近1年
df = df[df.index >= (pd.Timestamp.today() - pd.DateOffset(years=1))]
```

> 💡 **akshare** 是一个完全免费的 Python 金融数据接口库。这里用的是新浪接口，无需注册、无需API key，直接 pip install 就能用。

#### 第二步：计算均线

```python
# rolling(10).mean() = 每10天的滑动窗口平均值
df['MA10'] = df['close'].rolling(window=10, min_periods=1).mean()
df['MA30'] = df['close'].rolling(window=30, min_periods=1).mean()
```

> 💡 `rolling(window=N).mean()` 是 pandas 最强大的函数之一——它逐行计算最近N天的平均值，自动滚动。

#### 第三步：判断金叉/死叉信号

```python
# 金叉：昨天 MA10 ≤ MA30，今天 MA10 > MA30
if not holding and ma10_yest <= ma30_yest and ma10_today > ma30_today:
    # → 买入

# 死叉：昨天 MA10 ≥ MA30，今天 MA10 < MA30
elif holding and ma10_yest >= ma30_yest and ma10_today < ma30_today:
    # → 卖出
```

> 💡 通过「前一天 vs 今天」的均线位置关系来检测交叉事件，而不是简单看谁在上方。

#### 第四步：运行回测

```python
for i in range(30, len(df)):         # 从第30天开始（MA30有值）
    if buy_signal:
        buy_shares = int(capital // (close_price * 100)) * 100  # 整手买入
        capital -= buy_shares * close_price
        position = buy_shares
        holding = True
    elif sell_signal:
        capital += position * close_price  # 全部卖出
        position = 0
        holding = False
```

> 💡 回测的本质就是**逐日循环**：每根K线走一遍，有信号就操作，没信号就持有不动。

#### 第五步：统计指标

```python
# 累计收益率
total_return = (final_asset / initial_capital - 1) * 100

# 年化收益率（252 ≈ 每年交易日数）
years = trading_days / 252
annual_return = ((final_asset / initial_capital) ** (1/years) - 1) * 100

# 最大回撤
net_value_df['peak'] = net_value_df['total_asset'].cummax()
net_value_df['drawdown'] = (net_value_df['total_asset'] - net_value_df['peak']) / net_value_df['peak'] * 100

# 夏普比率
annual_vol = daily_returns.std() * np.sqrt(252)
sharpe_ratio = (annual_return / 100 - risk_free_rate) / annual_vol
```

## 第五章：如何从回测走向实盘

> ⚠️ **前方高危预警**：回测赚了钱 ≠ 实盘也能赚钱。本章帮你搭建一座从「纸上谈兵」到「真枪实弹」的桥梁。

### 5.1 回测和实盘的鸿沟

| 差异点 | 回测 | 实盘 |
|--------|------|------|
| **成交价格** | 假设以收盘价成交 | 实际成交价可能差很多 |
| **滑点** | 没考虑 | 每次交易都有 |
| **手续费** | 未计入 | 佣金+印花税+过户费 |
| **市场冲击** | 少量资金不影响价格 | 大资金买就会推高价格 |
| **网络延迟** | 瞬间完成 | 从下单到成交有延迟 |
| **心理压力** | 零压力 | 真亏钱会手抖 |

**解决思路**：在回测中加入**滑点模型**（如每次+0.1%滑点）和更**真实的手续费**，让回测更接近实盘。

### 5.2 东方财富接口简介

如果你想把代码变成真的能下单交易，需要连接券商的**交易接口**。

**东方财富（EastMoney）** 有三个层次的方式：

#### 方式一：akshare 数据接口（免费，只读）

```python
import akshare as ak
df = ak.fund_etf_hist_sina(symbol='sh510300')  # ETF历史数据
df = ak.stock_zh_a_spot_em()                   # 沪深A股实时行情
```

✅ 免费、无门槛、无需注册  
❌ **只能获取数据，不能下单交易**

#### 方式二：东方财富量化平台（图形化策略）

- 特点：在浏览器里写策略，平台自动执行
- 适合：不想自己搭服务器的新手

#### 方式三：券商 API 接口

部分券商提供 Python SDK 供量化交易：

| 券商 | 接口名 | 说明 |
|------|--------|------|
| **华泰** | xtquant | 提供Python SDK，支持实盘/模拟 |
| **中信** | 中信量化平台 | 门槛较高 |
| **开源方案** | vnpy + CTP | 连接期货公司，股票较复杂 |

> 💡 **对于新手**：最推荐的方式是先用 **东方财富APP的模拟交易功能**，手动执行策略信号来验证。

### 5.3 模拟交易建议

在真金白银之前，强烈建议至少做1~2个月的**模拟交易**。

| 正确做法 ✅ | 错误做法 ❌ |
|-------------|-------------|
| 严格按策略信号操作 | 凭感觉改来改去 |
| 记录每笔交易的滑点 | 觉得模拟盘无所谓 |
| 模拟1~3个月 | 模拟了3天就急着实盘 |

**模拟交易工具推荐**：东方财富APP（内置模拟炒股）、同花顺模拟、券商自带模拟盘。

### 5.4 实盘风险提醒 ⚠️

#### 🚨 第一条：只用闲置资金
```
实盘资金 = 亏了也不影响生活的钱
绝对不能：借钱炒股 / 用生活费炒股 / 压上全部存款
```

#### 🚨 第二条：从小资金开始
```
建议路径：1万 → 稳定盈利3个月 → 加到5万 → 稳定盈利6个月 → 加到10万
永远不要一步到位
```

#### 🚨 第三条：接受亏损是交易的一部分
```
最好的策略也会有亏损期
关键是：让利润奔跑，截断亏损
```

#### 🚨 第四条：注意实盘中新增的成本

| 实盘成本项 | 影响 |
|-----------|------|
| 滑点 | 可能吃掉0.1%~0.5%的利润 |
| 印花税 | 卖出时万分之5 |
| 最低佣金 | 部分券商有最低5元限制 |
