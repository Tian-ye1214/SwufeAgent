# 量化交易策略部署 Skill

将双均线策略（MA10×MA30）部署到东方财富量化终端，实现 510300（沪深300ETF）全自动交易。

---

## 适用场景

- 用户已有东方财富证券账户，想把量化策略跑成实盘
- 用户完成了本地回测验证，需要部署到真实交易环境
- 用户想从仿真交易开始逐步过渡到实盘
- 用户询问「怎么把策略真正跑起来」「怎么自动化交易」

---

## 前置条件检查

在开始部署前，确认以下条件：

| 条件 | 必须？ | 如何验证 |
|------|--------|----------|
| 东方财富证券账户 | ✅ 必须 | 已开户且可正常登录 |
| 风险测评已完成 | ✅ 必须 | 东方财富APP → 我的 → 业务办理 → 查看风险等级 |
| ETF交易权限已开通 | ✅ 必须 | 在交易页面试买入510300，看是否提示无权限 |
| Windows PC | ✅ 必须 | 东方财富量化终端仅支持Windows |
| Python 3.6+ | ✅ 必须 | 终端 `python --version` |
| 可用资金 ≥ 1000元 | ⚠️ 实盘需要 | 1手510300约470元+缓冲 |

## 工作流程（4个阶段）

### 阶段1：APP端准备（5分钟）

```
1. 东方财富APP → 我的 → 业务办理 → 风险测评（按实答题）
2. 东方财富APP → 交易 → 买入 → 输入510300 → 确认无权限问题
3. 确保证券账户有足够资金
```

**风险等级要求**：C3（稳健型）及以上即可交易ETF。

### 阶段2：PC端安装（30分钟）

```
1. 下载：https://emquant.18.cn → 下载Windows版 → 安装
2. 安装Python 3.9+（如未安装）：https://www.python.org/downloads/
3. 打开终端 → 左下角「量化」→ 等待自动安装完成
4. 终端 → 左上角「SDK下载」→ 选择 Python → 安装SDK
5. 终端 → 用户管理 → 密钥管理 → 复制 Token ID
```

**验证SDK安装成功：**
```python
from gm.api import *
print('SDK安装成功')
```

### 阶段3：导入策略并仿真（15分钟 + 1~2周观察）

```
1. 终端 → 量化研究 → 我的策略 → 新建策略
   - 语言: Python
   - 模板: 定时任务
2. 打开 main.py，粘贴 scripts/双均线策略_东财量化终端.py 全部内容
3. 修改代码底部 run() 中的：
   - strategy_id → 终端显示的策略ID
   - token → 第2阶段获取的Token
   - backtest_initial_cash → 实际本金（默认5000）
4. 先跑回测验证（终端内点击「运行回测」）
5. 创建仿真账户 → 运行仿真交易 → 观察1~2周
```

**仿真观察要点：**
- 信号判断准确（14:50金叉买、死叉卖）
- 下单数量正确（整手100股）
- 无异常报错

### 阶段4：切换实盘

```
1. 终端 → 实盘交易 → 连接东方财富证券账户
2. 如果提示资金门槛 → 告知用户可能需要切换到Plan B（easytrader方案）
3. 设置风控参数：
   - 单笔最大买入金额 = 总资金
   - 持仓上限 = 总资金
   - 日亏损上限 = 总资金的4%
4. 点击「运行」启动策略
```

## 策略参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `SYMBOL` | `SHSE.510300` | 交易标的（可换成其他ETF） |
| `MA_SHORT` | 10 | 短期均线周期（交易日） |
| `MA_LONG` | 30 | 长期均线周期（交易日） |
| `CHECK_TIME` | `14:50:00` | 每日信号检查时间 |
| `HISTORY_DAYS` | 50 | 取多少天历史数据计算均线 |

**参数调优建议：**
- 更激进：MA5 × MA20（信号更多，假信号也多）
- 更保守：MA10 × MA60（信号更少，更可靠）
- 更贴近收盘：`14:55:00`

## 常见问题

### Q: 策略跑了几天没信号，正常吗？
**正常。** 双均线策略几周甚至几个月才出现一次交叉。没信号=空仓等待。

### Q: 下单后没成交怎么办？
改为市价单：`order_type=OrderType_Market`。

### Q: 遇到资金门槛怎么办？
Plan B：同花顺 + easytrader 开源方案，零门槛。详见底部说明。

### Q: 想加止损功能？
在 `algo()` 中增加：
```python
if holding_volume > 0:
    avg_cost = pos.vwap
    if (close_price - avg_cost) / avg_cost < -0.05:
        order_volume(symbol=SYMBOL, volume=holding_volume, ...)
```
